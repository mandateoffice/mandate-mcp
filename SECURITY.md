# Security policy

Please report security issues privately by email to **info@mandateoffice.com**.
Do not open a public GitHub issue for a vulnerability.

Include what you found, the affected URL or tool (for example `https://mandateoffice.com/mcp`, tool name and arguments), and steps to reproduce.
We will acknowledge your report and keep you informed while we fix it.

This repository holds only client-side documentation and examples. The hosted server at mandateoffice.com is operated by Nukehive OÜ (Estonia, registry code 14647290).
